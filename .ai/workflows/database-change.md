# Workflow — Cambio de base de datos

1. Relacionar cambio con requisito/dominio.
2. Identificar servicio propietario del dato.
3. Verificar multi-tenancy.
4. Diseñar migración reversible o estrategia de rollback.
5. Evitar compartir tablas entre servicios sin decisión arquitectónica explícita.
6. Actualizar documentación de datos cuando cambie el modelo contractual.
7. Añadir pruebas de integración.
8. Evaluar compatibilidad con datos existentes.
