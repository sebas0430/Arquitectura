# QUICKPATCH — Glosario mínimo

- **Tenant:** empresa o espacio lógico aislado dentro de la plataforma.
- **RF:** requisito funcional.
- **RNF:** requisito no funcional.
- **RIE:** requisito de interfaz/integración externa según documentación del proyecto.
- **SRS:** Software Requirements Specification.
- **SAD:** Software Architecture Document.
- **SDD:** Software Design Description.
- **DD:** Documento de Diseño / datos y contratos.
- **ADR:** Architecture Decision Record.
- **API Gateway:** punto de entrada a servicios backend.
- **Matching:** selección/asignación de técnicos candidatos.
- **Outbox:** patrón para publicación confiable de eventos asociados a cambios persistidos.
- **OpenAPI:** contrato formal de API REST.
- **Contrato de evento:** esquema acordado para mensajes publicados/consumidos.
- **Cambio compartido:** cambio que afecta más de un área/rol a través de una frontera contractual.
